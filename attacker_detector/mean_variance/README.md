# `attacker_detector/mean_variance/`: SR/PM mean-variance benchmark package

This is the core library for robust mean and variance recovery under SR and PM. It is based on Li et
al., USENIX Security 2023. Every module works on one reporting round at a time. A model only ever
sees `Round.observation()`; labels, sources, targets and beta never reach it.

How the modules depend on each other, from the bottom up:
`transforms` → `mechanisms` → `estimator` → `knowledge` / `attacks` → `feasibility` →
`sources` / `populations` → `scenarios` → `experiment` / `store` → `features` → `methods/` →
`metrics` / `evaluate` / `validation` / `plots`.

| File | What it contains |
|---|---|
| `__init__.py` | Re-exports the step-1 API: `Transform`, `SR`, `PM`, `get_mechanism`, `split_groups`, `perturb_users`, `estimate`, `estimate_retained`, `exact_moments`, `Estimate` |
| `transforms.py` | `Transform(a, b, square_mode)` maps values onto [-1, 1]. g1 carries x; g2 carries the second-moment query in one of two conventions: `raw` squares x and then normalises (paper Sec. 2.2.1), and `normalized` normalises x and then squares (the default, which matches the paper's experiments). The x^2 range is correct for domains that cross zero. It also converts moments and sums between raw units and the benchmark scale (`norm_*`, `denorm_*`, `norm_sums` / `denorm_sums`, `query_mean`, `second_from_query`, `raw_targets`) |
| `mechanisms.py` | `SR` and `PM` classes: user-side `perturb`, `unbias`, server-side `decode` (Phi), and `cap`, the largest value one report can contribute (coth(eps/2) for SR, coth(eps/4) for PM). PM also has `interval`, `pdf`, `s`, `p_inside`. Plus `get_mechanism(name, eps)` |
| `estimator.py` | `split_groups` (exact random halves), `perturb_users` (honest reports), `estimate` (the server's mean, E[x^2] and variance, unclipped), `estimate_retained` (re-estimation after removal, with a per-group fallback), `group_decoded_means`, `exact_moments` (genuine truth, ddof 0), `Estimate` (raw moments, with `.normalized()`) |
| `knowledge.py` | `AttackerKnowledge(n_e, S1_e, S2_e)` and its regimes: `from_compromised` (h sampled users who stay genuine; the paper default), `exact` (oracle), `from_history`. `round_count` gives published-style n_e (`sig1`, `sig2`, `exact`) |
| `attacks.py` | Attack generators, re-derived from the estimator. `required_fake_sums` (paper and group-aware rules) and `unbiased_fake_sum` are the sums the fakes must deliver. `opa` handles SR (integer ±1 counts) and PM (`pm_spread`: sum-preserving spread, no clipping). `ipa_inputs` gives bounded fake inputs for IPA, by exact closed form or the paper's Adam (with a tangent-space gradient fix). `saturate=True` is the best-effort mode for below-budget runs only. `AttackStatus` is the generator outcome, kept separate from theoretical feasibility |
| `feasibility.py` | Theoretical checks run before generation, at a planned allocation of fakes to groups (m_1 = ceil(m/2), m_2 = floor(m/2)): `check_ipa` (joint sum and sum of squares), `check_opa` (SR integer counts with the resulting target error; PM output range and spread room), `check`. `minimum_budget` gives m_min, beta_min and q_t, with an oracle label; `budget_ladder` gives ceil(f * m_min); `needs_no_fakes`. Older helpers `beta_min`, `sufficient` and `*_sufficient` remain |
| `sources.py` | `SOURCES` holds the declared domain, column, filter, Table 3 statistics, printed targets and n_e for each dataset. `load_source` (with SHA-256 provenance and an `.npz` cache) and `audit` (comparison with Table 3). Covariates are used only to build subpopulations |
| `populations.py` | `record_partition` splits each source's records into train/val/test before any population is built. `PopulationRecipe`, `sample_recipe` and `build_population` create varied parent populations (subpopulation choice, rank-based exponential and quadratic tilting, Gumbel top-k sampling). `stable_seed` gives deterministic seeds |
| `scenarios.py` | `RoundSpec` describes one round fully and is seeded; its ids keep pairing across variants. `Round` holds the observation, labels and meta. `generate_round` runs the mandatory budget stage (m_min, theory check), then builds the round and records three outcomes separately: theory, construction and realized error. `resolve_targets` handles the `offset` and `absolute` target modes; `inject_knowledge_error` applies estimation errors on benchmark-scale sums |
| `experiment.py` | `load_config`, `PopulationBank` (lazy parent populations), `make_banks`, `enumerate_specs` (the main grid), `_sweep_specs` (one-factor sweeps), `_budget_specs` (budget ladder), `spread_for` (OPA-PM spread per replicate), `resolve_size` (handles `full`) |
| `store.py` | `RoundStore`: resumable generation with a JSONL manifest and one `.npz` shard per (split, protocol, eps, source). Recovers from a crash between saving a shard and appending the manifest. `load` returns observation arrays and labels separately |
| `features.py` | Feature views computed from the observation only. `report_features`: per report for PM (local density, kNN distances, percentile, round context) and SR (sign, cell frequencies), plus a `mech` ablation that adds residuals against `pm_mixture_fit`, a weighted NNLS fit of the group's histogram by PM output densities whose weights sum to one. The residuals measure disagreement with that fitted mechanism model, not verified evidence that a report is fake: poisoning that looks like another valid population is absorbed into the fit. Groups are fitted independently, and variation across admissible fits is not computed. `round_summary` gives fixed-length round features (CatBoost); `standard_moments`; `pm_kernel_matrix` |
| `metrics.py` | `UtilityScales` (loss scales from training rounds only), `project_moments` (feasible normalized moments), `squared_errors`, `accuracy_gain`, `shift_achieved`, `classification` (precision, recall, F1, PR-AUC, genuine removal rate, with clean-round conventions) |
| `evaluate.py` | `run_unit` trains once per (protocol, eps, training-source set), saves the checkpoint, and evaluates every destination, writing per-round rows that carry budget metadata. Also `evaluate_frozen` (checkpoints on unseen shifts), `rounds_from_store` (restricted to the configured round ids), `aggregate` (MSE, AG, quantiles, fraction of rounds made worse, population-clustered bootstrap CIs), `coverage_table`, `load_results`, `parse_unit_key` |
| `validation.py` | Paper-scale checks that need no training: `attack_validation` / `summarize_attack_validation` (MSE to target), `feasibility_maps` (oracle beta_min heatmaps), `kmeans_verification` / `summarize_kmeans_verification` (Sec. 8.1, Fig. 12; parallel, resumable, restarts its process pool), `budget_curves` (beta_min vs target, attacker estimate vs oracle) |
| `plots.py` | Figures (SVG + PNG + `.manifest.json`): `sweep`, `ag_bars`, `heatmaps`, `transfer_matrix`, `runtime_bars`, `kmeans_fig12`, `budget_curves_plot`, `utility_vs_budget`, `construction_by_factor`. Fixed `METHOD_STYLE` colours and labels |
| `methods/` | Recovery and detection methods; see `methods/README.md` |
